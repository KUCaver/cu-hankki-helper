# 편의점 한 끼 도우미

아동급식카드로 CU 편의점에서 밥을 먹는 아이가 먹고 싶은 상품을 먼저 고르면, 급식카드 결제 기준과 한 끼 금액 안에서 영양을 맞춘 조합을 추천하는 웹페이지입니다.

- 사이트: https://kucaver.github.io/cu-hankki-helper/
- 굿네이버스 서울인천권역본부 [Web:메이커스 1기] 1주차 웹서비스 실습 작품입니다.
- CU, 서울시, 굿네이버스의 공식 서비스가 아닙니다.

## 쓰는 법

1. [시작하기]를 누릅니다.
2. 오늘 쓸 수 있는 금액을 슬라이더로 맞추고, 먹고 싶은 상품을 1~2개 고릅니다.
3. 추천 조합과 추천한 이유를 봅니다. 과자를 고르면 비슷한 과자의 당·나트륨·지방을 비교해 줍니다.

## 데이터와 기준

- 가격: CU 공식 상품 페이지 (2026-11-16 확인)
- 영양 정보: 식품의약품안전처 식품영양성분 데이터베이스
- 결제 기준: 서울시 꿈나무카드 안내 (식사류 4,000원 이상일 때 간식 3,000원까지, 한 끼 단가 9,500원)
- 신호등 색: 어린이 기호식품 영양성분 신호등 표시 기준을 상품 한 봉지(개) 전체에 적용

가격과 결제 기준은 가게나 구마다 다를 수 있습니다.

## 만든 방법

Claude Code로 만들었고, 서버나 데이터베이스 없이 index.html 한 파일로 동작합니다.
